# Передача проекта «Жас ғалым»

Состояние на 16 октября 2026 года. Это передача существующего кода и результатов,
без новых экспериментов или изменения поведения моделей.

## Что передать

В локальной папке `artifacts/handoff-2026-10-16/`:

- `zhas-galym-handoff.zip` - исходники, данные, конфигурации, отчёты, прогнозы,
  реестр экспериментов и SHA-256 опись; распаковать в отдельную папку.
- `context-checkpoint.zip` - отдельно сохранённые веса пятиэпохового XLM-R
  от 23 сентября; распаковать рядом с основным пакетом с сохранением путей.
- `output/pdf/experiment-summary-ru.pdf` - одна страница: цель и результат
  каждого типа экспериментов; рядом лежит редактируемый текст.

Внутри основного пакета файл `START_HERE.txt` объясняет структуру и следующий шаг.
Личные переписки, учётные данные, настройки агентов, кэши Python и временные
фрагменты передачи не входят в пакет. Старые веса остаются на этом компьютере;
их местонахождение и размеры перечислены в `inventory/retained-local-files.tsv`.

## Как продолжить

1. Сначала прочитать `experiment-summary-ru.pdf` и `inventory/experiments.tsv`.
2. Для последних моделей использовать `research/september-23/`, его данные
   и `artifacts/autoresearch/*/run_metadata.json`; для августовских исследований
   использовать `research/july-september/` и сохранённый source-snapshot конкретного запуска.
3. Устанавливать зависимости по фактическому environment/run metadata нужного
   эксперимента: корневой `environment.yml` содержит незакреплённые версии,
   а несовместимость torchvision уже прерывала один из запусков.
4. До нового обучения проверить пути, контрольные суммы разбиений и протокол;
   снимок без `.git` не заменяет Git-окружение, которое требуется некоторым
   исследовательским командам для фиксации ревизии и изменённых файлов.
5. Когда Гульнар пришлёт новый шаблон, перенести в него содержание файла
   `reports/current-cycle2.docx`, сохранив проверенные метрики и таблицы.
   Шаблон ещё не получен; текущие Word-файлы не редактировались.

## Какие результаты считать итоговыми

- На исправленном августовском протоколе контроль: dev macro-F1 0,355949.
- Совместный замер 12 сентября: средний macro-F1 0,359315 → 0,370273 по трём
  парным seed; ограничения по четырём диагностическим показателям не выполнены.
- Новый корпус 23 сентября: 20 эпох focal loss - test macro-F1 0,366561
  у context-only и 0,348846 у dual-gated; один seed, описательное сравнение.
- Единственные передаваемые веса последней корпусной серии относятся к
  пятиэпоховому context-only (F1 0,361643), а не к двадцатиэпоховому результату.
  Веса dual-gated и 20-epoch были ранее удалены по просьбе пользователя.
- Старые и новые разбиения, dev и test, результаты статьи и локальные
  воспроизведения нельзя объединять в одну сопоставимую таблицу качества.
- Для нового корпуса нет идентификаторов исходных документов; близкие
  дубликаты/пересечения источников не проверены, test использовался повторно.
